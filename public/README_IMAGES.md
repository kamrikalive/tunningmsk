# Инструкция по добавлению изображений

## Изображения товаров

Поместите изображения товаров в папку `public/products/` со следующими именами:

1. `geely-okavango.jpg` - Пороги для Geely Okavango
2. `kia-sportage-4.jpg` - Пороги для Kia Sportage 4
3. `gac-gs8.jpg` - Пороги Gac GS8

## Фоновое изображение

Поместите фоновое изображение в папку `public/` с именем:
- `bg.jpg` - Фоновое изображение для главной страницы (опционально)

Если изображения не будут загружены, сайт будет использовать градиентный фон.

## Рекомендации

- Формат: JPG или PNG
- Размер изображений товаров: рекомендуется 800x600px или больше
- Размер фонового изображения: рекомендуется 1920x1080px или больше
- Оптимизируйте изображения перед загрузкой для лучшей производительности
